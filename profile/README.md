## ⚠️ Important Safety Considerations

Flashing firmware involves risks, especially when device compatibility has not been confirmed.

- An incorrect firmware package can cause startup failures or other software problems.
- Some operations erase all user data.
- Certain procedures require an unlocked bootloader and may not work on locked devices.
- Bootloader unlocking can reduce device security and may trigger a data wipe.
- Unofficial tools may contain unwanted software or make unsupported claims.
- Firmware flashing does not legitimately remove every account lock or ownership restriction.

If your phone is locked to a Xiaomi account or another security service, use the manufacturer's official account-recovery process or an authorized service center. Do not attempt to bypass ownership protections.
